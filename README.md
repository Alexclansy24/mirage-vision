# Mirage Vision

A real-time computer vision application built with Python, OpenCV, and Cactus Mirage. Mirage Vision captures live webcam frames, detects objects, and displays bounding boxes with detection labels.

The project explores lightweight AI vision models for local, real-time object detection.

## Features

- Real-time webcam video processing
- AI-powered object detection using Cactus Mirage
- Bounding boxes around detected objects
- Object labels and confidence scores
- Detection tracking support
- Unique detection IDs for identifying new inference results
- Frame resizing to improve inference performance
- Threaded detection worker to keep camera processing responsive
- Configurable detection confidence and inference interval

## Getting Started

### Prerequisites

- Python 3.10 or compatible version supported by your installed dependencies
- Webcam
- Windows, Linux, or macOS
- Internet connection for installing dependencies and obtaining the Mirage model if required

### 1. Clone the repository

```bash
git clone <your-repository-url>
cd mirage-vision
```

### 2. Create a virtual environment

Windows:

```powershell
python -m venv .venv
```

Activate it:

```powershell
.\.venv\Scripts\Activate.ps1
```

If PowerShell blocks activation, use:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

Make sure the Cactus Mirage package and OpenCV are installed in the environment.

### 4. Run the application

```bash
python app.py
```

The application will initialize the Mirage model and start processing webcam frames.

## How It Works

Mirage Vision uses a background detection worker to process camera frames.

1. OpenCV captures a frame from the webcam.
2. The frame is passed to the detection worker.
3. The worker resizes the frame when necessary.
4. The image is converted from BGR to RGB.
5. Cactus Mirage performs object detection.
6. Detection results are stored and assigned a new detection ID.
7. The renderer draws bounding boxes, labels, and confidence scores.
8. The processed frame is displayed.

## Configuration

Detection settings are maintained in:

```text
src/config.py
```

The configuration includes:

- `INFERENCE_WIDTH` — maximum width used for inference resizing
- `CONFIDENCE_THRESHOLD` — minimum confidence required for detections
- `MAX_OBJECTS` — maximum number of objects returned
- `INFERENCE_INTERVAL` — delay between inference cycles

Adjust these values according to your hardware and accuracy requirements.

## Performance

Mirage Vision uses a background thread for inference so that camera capture and detection can operate independently.

Performance depends on:

- CPU and available memory
- Webcam resolution
- Inference image size
- Number of detected objects
- Mirage model performance
- Inference interval

Reducing the inference resolution can improve processing speed, but may reduce detection accuracy for small objects.

## Limitations

- Detection accuracy depends on the Mirage model and its supported capabilities.
- Small or partially occluded objects may not be detected reliably.
- Object tracking requires tracking IDs to be generated by the tracking logic.
- Detection IDs identify new inference results; they are not necessarily persistent object tracking IDs.
- Performance may vary depending on the hardware and camera quality.
